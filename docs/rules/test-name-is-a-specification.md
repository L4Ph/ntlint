# test-name-is-a-specification

**info** · placeholder · cutoff 0.5

## What it asks

This test's name does not state a behaviour and its expected result.

## How the answer is read

**true** — The name says what is being tested rather than what should happen: a component or method name, a ticket number, a word like works, correctly or should work, or a restatement of the call.

**false** — The name states a behaviour and an expected result, in whatever words this codebase uses for them. A terse name that still names a result is false.

## When it is asked

subjects its gate accepts. Judged subject: test. Needs: model, test.

A cutoff is a claim about one corpus. `placeholder` means it was never measured, so this rule can only report a candidate.
